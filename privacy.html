개인정보처리방침

1. 구글 계정에서 이용하는 정보

이 프로그램은 구글 드라이브의 '앱 전용 숨은 공간(appDataFolder)'에만 접근합니다. 요청하는 권한은 https://www.googleapis.com/auth/drive.appdata 하나입니다. 사용자의 다른 구글 드라이브 파일, 메일, 연락처 등에는 접근하지 않습니다.

2. 저장하는 정보와 목적

같은 관리소의 PC들이 업무 기록·증빙 사진·기본정보·점검표를 서로 맞추기 위해, 각 PC의 자료를 위 숨은 공간에 파일로 저장합니다. 이 파일은 그 구글 계정으로 연결한 이 프로그램만 읽고 쓸 수 있습니다. 관리소가 '공유 암호'를 정하면 파일은 암호화(AES-256-GCM)되어 저장됩니다.

3. 제3자 제공·외부 전송

개발자는 별도 서버를 운영하지 않으며, 사용자의 자료를 수집·열람하거나 제3자에게 제공하지 않습니다. 자료는 사용자의 PC와 사용자 본인의 구글 계정 안에만 있습니다.

4. 로그인 정보 보관

구글 비밀번호는 프로그램이 받거나 저장하지 않습니다. 로그인 후 구글이 발급한 접근 토큰만 그 PC의 Windows 암호 보관 기능(DPAPI)으로 암호화해 저장합니다.

5. 삭제

  • 프로그램의 [연결 끊기]를 누르면 그 PC에 저장된 토큰이 지워집니다.
  • 구글 계정 설정 → 보안 → 타사 앱 연결에서 이 프로그램의 접근을 해제할 수 있습니다.
  • 구글 드라이브 설정 → 앱 관리에서 이 프로그램의 숨은 데이터를 삭제할 수 있습니다.
  • 각 PC에 입력한 자료는 PC 안에 그대로 남습니다.

6. Google API 서비스 사용자 데이터 정책 준수

이 프로그램이 Google API로 받은 정보의 사용은 Limited Use 요구사항을 포함한 Google API Services User Data Policy를 따릅니다.
